- FR4 Plate
- Sandwich mount

- Rotary encoder with push button

## 3\. Design

### 3.1 Layout

<div class="image-container">
  <Image src={layoutImg} alt="NexaPad Layout" />
  <p class="caption">NexaPad Layout</p>
</div>

The layout is rather simple. It's features a compact 3x4 hotswap switches matrix with a rotary encoder and an OLED screen. This provides 15 customizable input for each layer.  

### 3.1 Structure

<div class="image-container">
  <Image src={structureImg} alt="NexaPad Structure" />
  <p class="caption">Exploded view of NexaPad</p>
</div>

The macropad will be using sandwich mount configuration. The entire unit is secured by four M3 screws that pass through the bottom case, threading into the top frame. This allows for quick assembly/disassembly.

### 3.2 Case

The primary housing consists of a 3D-printed top frame and a deep bottom case. The top frame is designed to house the keyboard matrix, while the bottom case provides structural support and protection.

## 5\. Firmware

The device will come with QMK-based firmware with two options. VIA or Vial support.  
Both firmware is fully programmable and will be made open source once it launches.
